# AgentAI — 自主智慧體的時代

「不是聊天機器人，是會動手做事的 AI。」

一份純前端單頁式白皮書／簡報，介紹 Agent AI（自主智慧體）如何把「回答問題」變成「完成工作」。內容涵蓋八項優點、任務生命週期示範、數據與導入 FAQ，全中文（繁體）呈現。

## 功能亮點

- **八項優點**：自主性、工具調用、多步規劃、7×24 執行力、成本槓桿、持續學習、多代理協作、一致品質
- **任務生命週期動畫**：接收目標 → 拆解規劃 → 調用工具 → 驗證回報，附可重播的互動式終端機示範
- **數據統計**：滾動觸發的計數動畫（40%+ 工時節省、24/7 運作、95% 自動化、10x 部署速度）
- **FAQ 手風琴**：導入常見疑問
- **視覺效果**：自訂游標光暈、滾動揭示動畫、跑馬燈 ticker、卡片 SVG 微動畫

## 專案結構

```
.
├── index.html    # 頁面結構（語意化 HTML）
├── style.css     # 樣式與動畫
├── script.js     # 互動邏輯（滾動揭示、終端機示範、計數動畫）
├── agentai-*.png # 設計稿與截圖
└── AGENTS.md     # 開發環境說明
```

## 使用方式

零依賴、純前端，直接開啟即可：

```bash
# 直接開檔
open index.html

# 或起一個靜態伺服器
python3 -m http.server 8080
# 瀏覽器連到 http://localhost:8080
```

## 技術
